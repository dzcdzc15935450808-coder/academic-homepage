# Surface brief — homepage (index.html)

Mode: Read (visitors come to understand the person). Audience: film-studies scholars; job: quick credibility check.

## Direction contract

**THESIS:** An academic homepage read like a well-set repertory-cinema program note with Anthropic-grade editorial warmth: warm paper, a single clay accent, hairline rules, serif display, and film-slate metadata — refusing the category default of sidebar-card-plus-badge academic template.

**OWN-WORLD:** Paper ground (#f6f1e8 light / #17140f dark "screening room"), ink brown-black, one clay accent (#c2501f light, #d97757 dark). Faces: Newsreader (self-hosted serif display) + system sans body + system mono for film-slate labels (measurement metadata, not decoration). Components: 1px hairline rules, film-still photo frame with letterbox bars + mono caption, dashed news ledger, badge links as rounded pills, §-free section titles set in serif with a hairline underneath.

**STORY:** Within one viewport the visitor learns: name (localized), Barcelona PhD on CSC, comparative transitional-cinema research, founder of Kinoscholar. Scrolling reveals the doctoral project, news ledger, the project card, award, contact. Nothing claims publication where none exists.

**FIRST VIEWPORT:** Sticky top bar with name + nav + lang switch + theme toggle. Below: two-column editorial spread — left rail with photo presented as a film still (4:5, hairline frame, mono caption "DONG ZHECHENG — 2026"), name in serif at display scale, role/affiliation, two email links, link pills; right column: About set at comfortable measure (65–75ch), then Research. A vertical hairline divides the columns. Quiet by default; the photo is the only image.

**FORM:** Editorial program-note / film-essay page; first of my candidate list (the brief pinned the world, so no concept tournament was run — a brief-pinned direction beats the roll). SEED REFERENCE: none (brief-pinned world, no concept-seed run).

**SIGNATURE INTERACTION:** One authored motion: the film-still photo does a slow Ken-Burns drift on hover (6s, scale 1→1.04, translate 0→-1%), and the whole page settles in with a single soft fade-up on first load; everything else is instantaneous.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
